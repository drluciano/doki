# Doki project foundation

This is a reviewable setup package for drluciano/doki, not application code.

Contains role instructions, delivery policy, issue and PR templates, design/engineering proposals, 10 epics and 39 stories, and a complete machine-readable backlog. The existing repository README is preserved during publishing.

Start at docs/workflow.md and docs/backlog.md. G01 is the initial owner review. All subsequent application work waits for explicit selection and the documented readiness gates.

The owner corrected GitHub installation access after initial issue/branch writes were rejected. Repository metadata permissions alone did not prove connector write access. Project editing still requires an authenticated session or authorized Projects integration; the available browser is signed out and the connector exposes no Projects writes. No passwords or tokens should be sent in chat.

This package is published as a setup PR with repository issues. It does not merge, close issues, accept stories, modify branch protection, create a schedule, or overwrite the existing README. Project configuration remains a documented manual step until an authenticated editing connection is available.

Public project URL: https://github.com/users/drluciano/projects/2/views/5 . That view is My items with assignee:@me; choose Backlog or clear the filter to see unassigned stories. Proposed project status/priority configuration is documented in docs/workflow.md and is not installed by this package.
