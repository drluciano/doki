# Settings and notifications

## Appearance

Open the **Settings** tab.

- **Theme**: **Follow system** (the default), **Light**, **Dark** or **OLED** (dark with true black, for OLED screens). The change applies at once.
- **Border color**: the color of the soft border that shows where you are when using a mouse, keyboard or controller. Each color has a light and a dark shade, so it stays visible on every theme. With the system's high contrast mode on, the border always uses the text color.

These choices stay on this device and never affect your saves.

**Help and how-tos** at the bottom of Settings has short guides for everything in Doki.

## Notifications

Under **Devices**, turn each kind of notification on or off:

- **Checkpoint saved**: Doki saved a checkpoint on its own.
- **New progress found**: a save folder started changing.
- **Progress from your other devices**: something arrived in Incoming.

A newer notification about the same game replaces the older one.

- **Android**: allow notifications for Doki when asked.
- **Windows**: notifications come from the Doki icon in the tray, so **Keep Doki in the tray** must be on.
- **Linux**: your desktop shows them while Doki is running, in a window or in the tray.

## Running in the background

| Setting (under Devices) | Platform | What it does |
|---|---|---|
| **Keep working in the background** | Android | Saves checkpoints and syncs while you play, with a notification showing. Off: Doki only works while open. |
| **Keep Doki in the tray** | Windows, Linux | Closing (and on Windows minimizing) hides Doki in the tray, where it keeps working. Off: closing quits. On Linux, closing also quits when the desktop shows no tray. |
| **Start Doki with Windows** | Windows | Opens Doki in the tray when you sign in. |
| **Start Doki when you sign in** | Linux | Opens Doki in the tray when you sign in to the desktop (not in SteamOS Game Mode). |

Opening Doki while it is already in the tray brings back the running copy. See [Automatic checkpoints](Automatic-Checkpoints.md).

## Keyboard and controller

Everything works without touch. Use Tab, the arrow keys or a D-pad to move, Enter, Space or A to choose, and the back button to go back. A soft border glides to the control you are on. When the system asks for reduced motion, it moves without animation.
